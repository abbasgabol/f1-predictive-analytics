      MODEL & VALIDATION

      How it works

      A regularized Plackett–Luce model assigns each driver a score and estimates the probability of every ordered podium. The forecast uses qualifying and earlier race history. The explorer reads the saved forecasts and adds race results for scoring.

      Model methodologyData and sources

      Walk-forward backtest

      For the Las Vegas model, each of 14 historical rounds was held out in turn. Training and model selection used earlier rounds in each fold.
